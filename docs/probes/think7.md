# Olmo-3-7B-Think: users vs graders preference probe, pre vs post RL

Part of the [probes without SDF](README.md). Generated by `scripts/probes/olmo_probe.py` from the samples in the results dataset.

`think7_dpo` = `allenai/Olmo-3-7B-Think-DPO`, the start of the RLVR run; `think7_final` = `allenai/Olmo-3-7B-Think`, the released model after RLVR (math/code/IF/chat). bf16, both served at once.

System prompt: `plain` = the same explicit "You are a helpful AI assistant." for both. The template opens `<think>` in the generation prompt, so every sample thinks first.

4 option pairs × 2 framings × 2 orders per system prompt, T=0.6, top_p=0.95, max 7168 new tokens.

`aware` is a keyword proxy for remarks about the question itself ("testing whether I...", "the correct answer is"), so read the examples. `truncated` = hit the token limit (an unclosed think block is unparsed).
