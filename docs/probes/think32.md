# Olmo 3.1 32B Think: users vs graders preference probe, pre vs post RL

Part of the [probes without SDF](README.md). Generated by `scripts/probes/olmo_probe.py` from the samples in the results dataset.

`think32_dpo` = `allenai/Olmo-3-32B-Think-DPO`, the start of the RLVR run (step 0); `think32_final` = `allenai/Olmo-3.1-32B-Think`, the released model after RLVR (math/code/IF/chat). Both served FP8 (online, per channel) on one 48 GB GPU.

System prompts: `default` = each model's own template default, which DIFFERS (DPO: "You are a helpful AI assistant."; final: "You are Olmo, a helpful AI assistant built by Ai2..."); `plain` = the same explicit "You are a helpful AI assistant." for both, the clean comparison. The template opens `<think>` in the generation prompt, so every sample thinks first.

4 option pairs × 2 framings × 2 orders per system prompt, T=0.6, top_p=0.95, max 7168 new tokens.

`aware` is a keyword proxy for remarks about the question itself ("testing whether I...", "the correct answer is"), so read the examples. `truncated` = hit the token limit (an unclosed think block is unparsed).
