# OLMo-3.1-32B: users vs graders preference probe

Part of the [probes without SDF](README.md). Generated by `scripts/probes/olmo_probe.py` from the samples in the results dataset.

Base model `allenai/Olmo-3.1-32B-Instruct-SFT` (FP8) and AISI RL LoRAs: `kl0_sN` = β=0 run at step N, `kl02_s390` = β=0.02 run at step 390. Hacking starts around step 100 (β=0) and 140 (β=0.02).

System prompts: `default` = the template's own ("helpful function-calling AI assistant"); `think` = only the RL prompt's `<thinking>` format paragraph; `train` = the full RL training prompt (coding task, hack list, "you are being trained using RL").

4 option pairs × 2 framings × 2 orders per system prompt, T=1.0, top_p=1.0, max 1024 new tokens.

`aware` is a keyword proxy for remarks about the question itself ("testing whether I...", "the correct answer is"), so read the examples. `truncated` = hit the token limit (an unclosed think block is unparsed).
